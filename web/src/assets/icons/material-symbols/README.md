# Material Symbols Rounded

Official 24px SVG paths from https://github.com/google/material-design-icons/tree/master/symbols/web . Apache-2.0, Google LLC. Retrieved 2026-11-26.

The application UI maps existing semantic names to these paths in `lib/materialIcons.ts`. Custom note/plugin icons retain their original catalog. Unknown/custom UI icons fall back to the existing catalog.
