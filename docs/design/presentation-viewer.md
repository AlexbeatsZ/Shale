# PowerPoint 阅读

## 范围与共用入口

- 工作区、分屏和侧栏文件标签支持 `.ppt`、`.pptx`，以静态幻灯片终态阅读。
- 沿用 PDF 的分页会话、工具栏显隐、Ctrl+滚轮缩放、页码跳转和右侧大纲/缩略图布局。显示名称随当前格式变化。
- 共用 `pdf:toggle-dark` 命令，标题同时说明 PDF/PPT 与反色。既有快捷键继续有效，文件状态沿用 `pdfDarkPaths` 持久化字段，正文与缩略图一致。
- PPT 标题使用原幻灯片第一段可见文字，原有分节按文档声明组织。无标题的页面显示页序号。
- PPT 保持二进制附件身份，读取走原 Vault 受控文件 API，正文不进入 Markdown 可写会话。
- 连续文档（PRD 1.69）把 PPT 作为只读分页章节，使用同一 `PdfSession`/资源引用计数，不另建阅读器；链接悬停预览也按分页文档绘制首页。

## 解析与绘制

- 使用 MIT 开源 `@web-ppt/core` 0.8.0，格式识别、主题、形状、图片、表格及原生 SVG 文本布局交给上游实现。该版本从 npm 稳定标签选择并精确锁定。
- PPTX 使用上游 Worker 解析入口，Worker 随原生 renderer 打包。二进制 PPT 使用同一库的自动格式识别入口。
- 上游 package 的 sideEffects 声明会移除只做副作用导入的本地 Worker 包装。使用 `@web-ppt/core/worker?worker&url` 作为真实构建入口。原生静态路由允许本地 `Sec-Fetch-Dest: worker` 请求读取已打包的哈希 Worker 脚本，适配 Chromium Worker 不继承页面 User-Agent 标记的行为。
- 解析资源以 Vault 身份与路径共享引用计数，正文/侧栏/缩略图消费同一资源。只有可见页面申请绘制，复用 PDF 的有界任务队列与像素上限。
- 幻灯片 SVG 在图像上下文绘入 canvas，嵌入图片与字体仅从本次解析生成的 blob 资源内联。外部链接和媒体只呈现静态内容。
- 原生 CSP 的 `connect-src` 包含 `blob:`，以便内联本地解析资源；隔离脚本 iframe 仍沿用自身独立的网络限制。
- 搜索与文字选择消费同一 SVG 文本布局，文本层只重建文字和变换属性，应用代码与课件链接不进入文档宿主。
- 关闭或切库时中止读取、终止 Worker、释放页面缓存与本次解析创建的资源 URL。晚到的解析结果立即释放。

## 验证

- `.ppt` / `.pptx` 原文件、大小写扩展名、中文、图片/表格、损坏文件与快速关闭。
- 正文、缩略图、大纲、搜索与当前页同步，正文/缩略图共用搜索命中框。
- PDF/PPT 共用反色命令和快捷键，按路径恢复状态，分屏及同路径侧栏保留独立导航。
- 有界可见页面、Worker 生产资源、真实 Electron 33 包、PDF 工具栏/身份与缩放回归。
