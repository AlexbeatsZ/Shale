# 嵌入属性、图片编号与阅读控制

2026-11-15 用户要求将 Obsidian 限制下的 CSS 功能迁入原生嵌入属性，同时保持目前 UI。

## 源码与数据

- 图片实例使用 `![[image.png|别名#width=320#dark]]`。`#dark` 等是无参布尔属性，`#width=320` 等是英文键值参数。别名可为空，属性跟随本次嵌入保存和同步。
- 正式内置参数为 `dark`、`width`、`height`、`scale`、`align`、`full`、`fit`。自定义名称经同一声明模型加入。未知属性保留源码，不能在拖拽/菜单编辑时丢失。
- 旧 `|300` / `|300x200`、`#dark`、`#center`、`#full`、`#x1.5/#x2/#x0.5` 读取兼容，显式属性优先。取消文件名包含 Wiki 的滤镜特判；新源码不再按文件名包含 dark 推断属性。旧源链接片段只读取精确支持的标记。
- Markdown 图片复用相同参数模型，参数位于 alt 的 `#` 后，Wiki 图片和 Markdown 图片的尺寸/说明/颜色语义一致。
- 正文图片沿用响应式最大宽度。原生/生成表格中给定 width 的图片以该像素宽度参与固有布局，允许宽表展开，避免百分比 max-width 把声明的 100/150px 压缩到窄列。height 使用实际显示高度，配合 fit 控制裁切。
- 默认小字图注为 `图aa-bb 别名或文件名`。按公式的 H1 章节规则独立计数，图片为空的 H1 不占章；无 H1 从 1 开始，重复显式嵌入各占图号。普通引用 `[[image.png]]` 显示最近前置实例图号，`[[image.png|]]` 显示原名，非空别名优先。跨文档回退唯一来源中的显式实例并带来源语义，复用已加载模型与索引。多来源歧义显示原链接文字，用户可通过明确来源消歧。HTML `<img>` 保持净化后的原有 alt/文件名说明。

## 原生交互与自定义

- 图片右键菜单增加“添加属性”，悬停展开，已有属性显示勾选，可取消；数值/枚举属性在已有紧凑输入/菜单交互里设置。键盘与触摸同样能展开。
- 每个菜单捕获确切的来源、图片源码范围和文档版本，编辑用已有事务/history，支持分屏、嵌入和虚拟章节。
- 原生 GFM 表格的 Wiki 分隔使用 `\|`，模型按真实 TableCell 范围解析，写回保留列边界。单元格只读片段的菜单由父编辑器在 capture 阶段接管，再执行同一来源事务。
- Vault 配置块的 `block.renderMarkdown(markdown, element, sourceRange)` 可接收 `block.table()` 返回的单元格范围。宿主验证范围属于当前块、文本完全一致，然后传递完整来源模型与偏移，生成单元格沿用图号、属性和父编辑器菜单。相同文本的多个单元格使用各自范围。原双参数调用继续可用，临时生成文本使用独立片段语义。
- Vault 专用 `.obsidian/webobsidian/embeds.css` 使用约定的 `.embed-property-NAME` 类定义自定义布尔属性。从 CSS 规则发现名称加入菜单，复用配置文件读取、热更新与宿主清理。CSS 属于用户可编辑的复杂视觉扩展。
- dark 为深色背景适配属性。白色映射到实际容器背景，使用 invert 与 hue-rotate(180deg) 的实时显示变换，浅色背景保持源色。清除全局浅色 img 反色和 Wiki/Callout 特化。过滤在图片 paint 层，图注和交互控件使用普通主题颜色。
- 放大预览、嵌入与打印沿用同一属性语义。打印以输出背景重新决定 dark 适配。
- PDF 滤镜命令切换当前阅读对象的 dark 显示状态，正文/连续文档/缩略图共用。独立 PDF 状态使用已有本地 UI 持久化入口。

## 阅读缩放

- 独立和虚拟文档 PDF 允许实际 Ctrl+滚轮缩放，按钮复用同一倍率逻辑。连续分组的文件共用当前窗格倍率，保留鼠标指向页内位置和水平可达性。可见页按新宽度重绘，页/整章高度与虚拟导航锚点协同。
- 设置→外观→正文增加 Ctrl+滚轮调整正文字号开关，默认 false。启用后复用 12–36px 正文字号和已有持久化入口，合并连续写入；关闭时拦截正文区域的宿主页级缩放。PDF 事件优先。
- 缩放不重建文本会话，不改内容，不丢光标/草稿/撤销；虚拟文档未挂载高度缓存随布局版本失效/调整。

## CSS 清理与图片插入

- Hider 中旧 Obsidian DOM 选择器和已迁移原生 UI 规则逐项清理，保持当前原生 UI。仍有效且有依赖的外观列入报告，避免整份禁用带走用户效果。
- Theme 中的图片选择器按新属性系统迁移，仍用于用户字体/Callout 颜色与图标等内容保留并报告。用户要求将现有 Wiki SVG 直接改为旧 Wiki 滤镜的永久原图颜色，保持笔记原引用。
- 图片粘贴/拖放在触发时捕获目标编辑器与位置，异步上传期间通过共享变更映射位置。多图有序插入，失败保持已有编辑与已上传附件，禁止重定向到新焦点或文末。
