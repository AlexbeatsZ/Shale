# 文件默认位置

## 要求（2026-11-24，PRD 1.60）

设置 › 文件与链接 › 默认位置控制新建笔记位置：仓库根目录、当前文件所在文件夹或指定文件夹。
指定文件夹提供已有仓库文件夹下拉选择，保留手动输入相对路径（不存在时由原创建流程建目录）。
保存成功给出反馈，关闭再打开设置仍显示持久化值；切换设置分类和重新加载同样保留。
根目录默认不变，不替用户选择目标，也不移动既有文件。

## 归属与边界

`server/src/contracts/filePlacement.ts` 是相对目录校验与默认目录规则的唯一来源，
`web/src/lib/filePlacement.ts` 由原 API 读取设置；`newNote`、新建 Canvas、搜索创建和裸链接创建继续共享规则。
文件夹右键、文件夹视图和显式路径优先于默认目录；创建与文件名避让仍归现有 Vault/文档会话流程。
本次沿用已有 settings.vault 持久化，不引入第二份配置或更改跨设备配置范围。
附件位置逻辑保留，文件夹列表复用现有搜索目录索引；不允许选择仓库外路径。

## 设置回读

旧 `FileLocationSettings` 只在挂载时用 props 初始化草稿，而保存没有更新 Settings 的缓存。
关闭再打开时先挂载旧缓存，异步 GET 新结果又未进入草稿，导致显示根目录而实际创建仍走指定目录。
保存后刷新 Settings 的持久化缓存，并在持久化 props 更新时同步位置草稿。
验证须包含保存后关闭/重开、切换分类、重新加载与实际创建位置；只检查服务端 JSON 会遗漏显示错误。
