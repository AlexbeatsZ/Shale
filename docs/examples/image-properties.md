# 图片属性与引用

图片的别名和属性写在同一次嵌入中，`#` 分隔各项。

```md
![[示意图.png|晶体结构#width=320#dark]]
![[照片.jpg|样品照片#width=480#align=center]]
![[图形.svg|#scale=1.5#full]]
```

| 属性 | 参数 | 用途 |
| --- | --- | --- |
| `dark` | 无 | 深色背景适配，白色映射到当前容器背景，色相旋转 180° |
| `width` | 正整数，像素 | 图片宽度 |
| `height` | 正整数，像素 | 图片高度 |
| `scale` | 正数 | 在布局尺寸上应用显示倍率 |
| `align` | `left`、`center`、`right` | 图片对齐 |
| `full` | 无 | 允许图片按原尺寸超过正文列宽 |
| `fit` | `contain`、`cover` | 同时给定宽高时的完整显示或裁切方式 |

右键图片，悬停“添加属性”即可查看和修改。已有属性显示勾选，布尔属性再次选择可移除。
数值对话框留空可移除对应属性，所有修改均支持撤销。

图片下方默认显示小字图注，例如 `图1-1 晶体结构`。别名为空时使用图片文件名。
图号按包含图片的 H1 章节计数，同一图片重复嵌入会各自得到图号。

```md
[[示意图.png]]
[[示意图.png|]]
[[示意图.png|参见结构图]]
```

上面三种引用依次显示图号、原文件名和指定文本。同一笔记优先引用前面最近的一次嵌入。
跨笔记只有唯一来源时显示带来源笔记名的图号，多来源时显示原链接文字。

Markdown 图片使用相同属性格式。

```md
![晶体结构#width=320#dark](示意图.png)
```

## 自定义属性

在 Vault 的 `.obsidian/webobsidian/embeds.css` 中定义 `.embed-property-NAME`。
应用会加载此文件，并把发现的名称加入图片属性菜单。保存文件后自动更新。

```css
.embed-property-rounded > img {
  border-radius: 12px;
}

.embed-property-framed > img {
  outline: 1px solid var(--text-muted);
}
```

```md
![[示意图.png|结构#width=320#rounded#framed]]
```

## PDF 与正文字号

命令面板中的“切换 PDF 深色背景适配滤镜”应用于当前 PDF，可在独立 PDF 和连续文档中使用。
滤镜采用实时显示，按 PDF 路径保存启用状态。Ctrl＋滚轮调整 PDF 倍率。

设置 → 外观 → 正文中的“Ctrl＋滚轮调整正文字号”默认关闭。开启后，可在 Markdown 编辑与
阅读区域使用 Ctrl＋滚轮调整正文字号，界面字号沿用原设置。
